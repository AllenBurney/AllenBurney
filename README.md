## Featured Projects

### 🏛️ [PoliCrime (NyayaNazar)](https://github.com/)
Civic transparency site tracking criminal records of Indian politicians — 4,600+ records across 32 elections, scraped from MyNeta.info with filtering, search, and ECI affidavit links.

---

### ⚽ [EPL Stats Site](https://github.com/)
Flask + HTML/JS site showing live EPL standings, team stats, and player stats via the `sportsipy` Python library.

---

### 📰 The Wire — Global Election Tracker
Single-file HTML/JS site auto-refreshing global election results as they come in, wire-service aesthetic, no manual updates.

---

### 🇮🇳 India Explained Through Data
Eleven-page data visualization platform on India's economy, population, health, and agriculture — inspired by Our World in Data, built with Chart.js and an interactive SVG map of all 28 states.

---

### 🎬 SubFinder
Single-file subtitle search tool powered by the OpenSubtitles API.
